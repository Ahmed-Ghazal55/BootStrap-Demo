# Bootstrap Demo (Legacy Learning Project)

A small HTML/CSS/Bootstrap frontend practice project featuring a responsive training-site layout. Preserved as a historical learning exercise.

## Run
Open `index.html` in a browser or serve the folder with `python3 -m http.server 8000`.

## Scope and status
This is a visual training demo rather than a production application. The page currently references multiple Bootstrap CSS variants and some external CDN assets; verify which are required before removing any.

## Maintenance plan
1. Test layout on phone, tablet and desktop.
2. Consolidate duplicate Bootstrap imports after visual regression checks.
3. Correct CSS-versus-JavaScript asset tags where necessary.
4. Improve semantic HTML, accessibility, navigation and images.
5. Add screenshots, credits for third-party assets, and a repeatable smoke checklist.

**Preservation policy:** retain the repository; README improvements are allowed but no deletion or archival.
